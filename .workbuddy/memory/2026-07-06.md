## jiangxiai.top 官网介绍视频生成（已完成）
- 使用 Remotion 框架（React 组件 → MP4）为 jiangxiai.top 官网生成内容介绍视频
- 通过 WebFetch 抓取网站全部内容，设计 6 场景 60 秒视频故事板
- **项目路径**：`remotion-videos/`（独立于主站项目）
- **视频参数**：1920×1080 Full HD, 30fps, 1800 帧（60 秒）, H264 编码, 5.4MB
- **6 个场景**：开场品牌(5s) → 四大身份(13s) → 五大纵深(14s) → 活动回顾(12s) → 城市覆盖(8s) → CTA(8s)
- **技术栈**：Node.js v22.22.2 + Remotion 4 + FFmpeg + Chrome Headless Shell
- **输出文件**：`remotion-videos/output/jiangxiai-intro.mp4`
- 所有场景组件采用 Constants-First Design 模式，动画使用 interpolate + spring + Sequence
- **追加解说旁白**：使用 edge-tts（zh-CN-YunxiNeural 男声）为6个场景生成中文解说语音，修改 VideoComposition.tsx 添加 Audio 组件后重新渲染
