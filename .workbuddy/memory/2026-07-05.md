## SEO 全面诊断分析（已完成）
- 对 jiangxiai.top 进行了完整 SEO 审计，覆盖 on-page / 技术 SEO / 百度 / Google 四维度
- **On-page SEO（85分）**：基础扎实——9 页面均有 title/description/canonical/OG/lang=zh-CN，index 有 Organization+WebSite+FAQPage JSON-LD，geo 标签完整，每页 H1=1，图片 alt 全覆盖，sitemap/robots 可访问
- **百度 SEO（20分）**：核心问题是 GitHub Pages 托管——百度爬虫无法稳定抓取 GitHub Pages IP（185.199.108-111.153），且 .top 域名无 ICP 备案，百度降权处理。site:jiangxiai.top 基本无收录
- **Google SEO（60分）**：Googlebot 可正常抓取 GitHub Pages，但未见 GSC 验证 meta（google-site-verification 缺失），sitemap lastmod 过时
- **技术问题**：无 HSTS/安全头；Cache-Control 仅 max-age=600；ecosystem-preview.jpg 276KB 未转 WebP；两个 GitHub Actions workflow（Jekyll+Static）可能冲突；keywords meta 444 字符过长
- **托管建议**：百度 SEO 唯一出路是迁移到国内服务器（腾讯云/阿里云）+ ICP 备案；海外服务器（Vercel/Cloudflare）为过渡方案；GitHub Pages 对百度 SEO 是死路
