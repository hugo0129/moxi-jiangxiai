## 活动/新闻列表页开发完成

### 新增文件
- `news.html` — 活动/新闻列表页，时间线布局，含筛选功能（全部/官媒报道/公众号推文）
- `news-data.json` — 24 条新闻/活动数据，按时间倒序，含日期、来源、类型、标题、摘要、外链

### 修改文件
- `main.js` — 新增新闻列表渲染逻辑（fetch JSON → 排序 → 筛选 → 时间线渲染 → IntersectionObserver 动画）
- `styles.css` — 新增 news-hero、news-filters、news-timeline、news-item、news-badge 等完整样式，含响应式适配
- `sitemap.xml` — 添加 news.html 条目
- 所有 10 个 HTML 页面（index/404/ecosystem/talents/aidaily/changelog/services/about/opc/news）— 导航栏和 Footer 均添加"活动/新闻"入口

### 数据结构
- sourceType: `media`（官媒报道）、`wechat`（公众号推文）、`event`（活动预告）、`voice`（行业发声）
- 当前数据：24 条，涵盖 2025-10 到 2026-07
- 维护方式：只需编辑 news-data.json 追加记录即可

### 修复问题
- JSON 中中文引号（ASCII 双引号）导致解析错误，已替换为 Unicode 弯引号（U+201C/U+201D）
- **fetch 在 file:// 协议下被浏览器阻止**：将 news-data.json 转为 news-data.js（`window.NEWS_DATA = [...]`），通过 `<script>` 标签加载，无需服务器即可直接打开 HTML 预览
- main.js 中 fetch 逻辑改为直接读取 `window.NEWS_DATA`
- 后续维护：编辑 news-data.json 后需运行 Python 脚本重新生成 news-data.js（或直接编辑 news-data.js）

## 导航二次重构（V3 最终版）

### 背景
V2 的"动态"下拉混合了不同性质的内容（OPC社区=核心功能 / 活动/新闻=组织动态 / AI日报=行业资讯），逻辑不通。从"江西 AI 圈"和"江西 OPC 联盟"双重定位出发重新设计。

### V3 导航结构（最终版）
```
首页 | 生态 | 社区 | 人才 | 服务 | 更多▾ | 加入我们
                              ↓
                         ├ 关于我们
                         ├ 活动/新闻
                         ├ AI 日报
                         └ 更新日志
```

### 分类逻辑
- **平铺 5 项 = 核心 5 大支柱**
  - 江西 AI 圈 → 生态（品牌）+ 人才（引力场）+ 服务（商业化）
  - 江西 OPC 联盟 → 社区（物理空间+超级个体孵化）
  - 首页 = 聚合总览
- **"更多"下拉 = 低频辅助/资讯内容**

### 关键改变（vs V2）
1. OPC 社区从"动态"下拉提升为平铺项（它是核心功能页，不是动态）
2. "动态"改为"更多"（不再强行将不同性质内容归为一类）
3. 关于我们/活动新闻/AI日报/更新日志 统一收纳进"更多"

### 内容去重
- 所有页面 Footer "品牌矩阵"链接从 `services.html#brands` 改为 `ecosystem.html`（完整版所在地）
- 首页第 5 个入口卡片从"关于我们"改为"活动/新闻"（关于已在"更多"下拉，活动新闻需要首页曝光）
- services.html 品牌矩阵保留精简版+链接到 ecosystem.html

### CSS 新增
- `.nav-drop-menu a.active` 样式（下拉项当前页高亮）
- `.nav-dropdown:has(.nav-drop-menu a.active)` 触发器联动高亮
- 移动端下拉内联显示样式

### Bug 修复
- 下拉菜单 hover 断联问题：`top: calc(100% + 14px)` 的 14px 间隙导致鼠标移过时 `:hover` 丢失，菜单消失。修复：在 `.nav-dropdown::after` 添加透明桥接区（height: 18px, pointer-events: auto）填补间隙；移动端通过 `.nav-links.show .nav-dropdown::after { display: none }` 禁用
