## 🔭 我眼中的“江西 AI 圈”

### 1. 它不是什么，而是什么
- **不是资本狂欢的炒作场**：我们不讲空洞宏大的叙事，不追逐虚浮的技术概念，不搞纯中介或培训套路；
- **是一个务实聚合的“实践共识体”**：它由江西本土的技术开发者、实体创业者、青年创客与超级个体自发凝聚而成。大家带着真实的业务痛点、真实的工作流程和真实的数据条件，在这里交流最朴素的提效路径与代码实践。

### 2. 发展脉络：从点到面，从赣鄱走向全国
- **本土扎根，多城共振**：
  - **2025.08** 从南昌发起，10 月举办南昌第 1 期线下沙龙，点燃本土同行连接的火种；
  - **2025.12** 滕王阁跨年聚会，与本土创业者共同确立**“业务真落地”**核心共识；
  - **全省星火**：九江（2025.12）、赣州（2026.02）、宜春（2026.03）、抚州（2026.03）、景德镇（2026.03）相继落地首期线下活动，让全省各地的 AI 同行走出“技术孤岛”；
  - **赛事与夜校**：主办江西首场 OpenClaw × OPC 龙虾局（MiniMax 支持）、第 1 期赣客松（真需求黑客松）、南昌 AI 夜校与高校技术切磋，持续培育本土青年技术力量。
- **跨省连接，代表发声**：
  - 受邀参加**杭州全国首届 AI+OPC 大会**，《江西日报》以《跨越钱塘潮》深入报道江西创新力量；
  - 赴温州参加 **2026 人工智能 OPC 创业者生态大会**登台分享，与全国十城共同发起《全国人工智能 OPC 社区共建公约》；
  - 受海南澄迈县科工信局邀请，担任**“超级个体进化营”导师与路演决赛评委**，作为导师代表点评全国创新项目；
  - 亮相**厦门 WOPC 金砖大会**，持续与全国一线生态高频互动，将外部前沿资源反哺江西。
- **深入产业，透视 OPC 社区生态**：
  - 实地调研南昌 5 大典型 OPC 社区（**众灿·迈奇**、**思佰尔**、**安澜 AI**、**XSPACE 豫见里**、**春秋星链**），从业务分发、短视频流水线、创投孵化、商圈综合体到服务市场撮合，中立透视各空间的真实运营路径与成本模型，为个人开发者提供清醒客观的决策参考。

### 3. 核心精神：一个人就是一家公司（OPC）
AI 时代赋予了个体前所未有的生产力杠杆。**“一人公司”（One Person Company）**不是噱头，而是一种全新的生产组织方式。江西 AI 圈秉持**“真诚利他、长期主义、本土落地”**的信条，让每一位愿意深耕技术的超级个体，在赣鄱大地上都能找到同频前行的伙伴。

## 💻 本地运行与预览

本项目为纯静态现代 Web 站点，无需任何复杂构建工具，开箱即用：

```bash

cd compliant-site

# 启动本地服务
python3 -m http.server 8088

# 浏览器访问
open http://localhost:8088/
```
