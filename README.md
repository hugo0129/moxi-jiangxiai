# 莫西AI · 智能实战笔记 (moxi-jiangxiai)

江西 AI 圈实践观察与一人公司（OPC）实操记录。

## 核心页面
- `index.html`：首页与实战全景
- `about.html`：关于莫西 · 江西 AI 圈实践观察初衷与成长足迹里程碑
- `opc.html`：南昌 OPC 社区走访名录与 5 大典型模式深度观察
- `events.html`：江西各市首期沙龙、高规格大会与技术切磋实录
- `solutions.html`：业务场景与实操技术方案
- `ecosystem.html`：生态连接与合作网络
- `aidaily.html`：AI 每日动态与实战观察
- `talents.html`：AI 开发者与实战人才画像
- `changelog.html`：更新日志与演进记录
